# Nuren Tasnim Risha — Portfolio

A responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `nuren-tasnim-risha-portfolio`).
2. Upload all files and folders from this package to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

The resume button points to `assets/Nuren_Tasnim_Risha_CV.pdf`. Keep that file in the same location.
